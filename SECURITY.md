# Security policy

Do not report vulnerabilities in public issues. Contact the project maintainers privately
through the SIH team channel.

Never commit database URLs, passwords, service-role keys, access tokens, raw personal data
or field-report evidence. The browser may receive only the Supabase project URL and
publishable key. Database credentials and administrative imports remain server-side.

Supported security fixes target the latest `main` branch during the SIH 2026 development
cycle.
